## 🚀 使用功能說明

### 題目瀏覽

每道題目頁面包含：

```
第 X 題（當前進度）

【題目文本】

○ A. 選項 A
○ B. 選項 B  ← 選擇一個選項
○ C. 選項 C
○ D. 選項 D

[⬅️ 上一題] [🦴 顯示答案] [下一題 ➡️]
```

### 功能按鈕

| 按鈕 | 功能 |
|------|------|
| **🐕 隨機** | 打亂題目順序，隨機播放 |
| **🐶 重置** | 清除進度和答案，恢復原始順序 |
| **⬅️ 上一題** | 回到前一道題目 |
| **🦴 顯示答案** | 自動選擇正確答案並顯示解釋 |
| **下一題 ➡️** | 進到下一道題目 |

### 進度追蹤

頁面會顯示三個重要指標：

- **題目**：第 X 題 / 總題數
- **正確率**：已做題中的正確百分比
- **進度**：完成百分比（視覺化進度條）

## ❓ 常見問題

### Q: 兩種模式可以同時使用嗎？
A: 可以！兩種模式各自獨立，進度互不影響。你可以在兩者之間自由切換。

### Q: 進度會保存嗎？
A: 會！系統自動保存在瀏覽器本地（localStorage）。清除瀏覽器快取會丟失進度。

### Q: 能導出進度嗎？
A: 目前不支援，但每個題庫的進度都有實時顯示。

### Q: 題目順序可以改嗎？
A: 可以！點「🐕 隨機」打亂順序。想恢復原始順序請點「🐶 重置」。

### Q: 某個檔案無法載入？
A: 檢查以下事項：
1. 檔案名稱是否拼寫正確
2. 檔案是否在與 `index.html` 同目錄
3. 瀏覽器的開發者工具（F12）是否有錯誤訊息

### Q: 我想只用原始題庫或只用 10 單元可以嗎？
A: 完全可以！系統預設載入兩種模式，但你可以只點擊想用的模式。
