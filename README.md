# AI 認證練習系統 - 三題庫整合版

## 📋 系統說明

本系統整合了三個不同的 AI 認證考試題庫，支援在同一個平台上練習不同的認證考試。

### 包含的題庫

1. **人工智慧工程素養認證 (200題)**
   - 依資訊工業策進會公開樣題編製
   - 四大主題：倫理、Python、理論、應用
   - 題目難度齊全

2. **生成式AI能力考試 (100題)**
   - 基礎知識、能力強化、應用技能、倫理法律
   - 快速入門練習

3. **生成式AI能力考試 (200題)**
   - 完整的生成式AI深度練習
   - 四大主題全覆蓋

## 📁 檔案結構

```
AI_Practice_System/
├── practice.html           ← 🎯 主要練習系統（新版 - 三題庫整合）
├── index.html             ← 原版系統（單一題庫）
├── all_questions.json     ← AI工程素養認證 200題
├── genai_100.json         ← 生成式AI 100題
├── genai_200.json         ← 生成式AI 200題
└── README.md              ← 使用說明（本文件）
```

## 🚀 快速開始

### 方式一：本地使用（推薦）
1. 下載整個資料夾到電腦
2. 用瀏覽器打開 **`practice.html`** （新版三題庫版本）
3. 點選頂部的頁籤選擇要練習的題庫
4. 開始練習！

### 方式二：使用原版系統
1. 打開 **`index.html`** 可以練習 AI工程素養認證 200題
2. 功能完全相同，但只有單一題庫

## 🎯 使用技巧

### 選擇部分練習
每個題庫都可以選擇特定部分，適合針對性學習：
- 倫理薄弱？選擇「倫理」部分集中練習
- 想快速複習？選擇「全部」隨機測試

### 隨機順序練習
點選「🔀 隨機順序」按鈕，打亂題目順序：
- 增加難度
- 練習快速反應
- 模擬正式考試

### 題目分類練習
- **AI工程素養**：4個部分，各40-80題
- **生成式AI 100**：4個部分，各25題
- **生成式AI 200**：4個部分，各50題
